A word drawn as a line that lays itself down, stroke by stroke, in the order a hand would write it. For a splash screen, an onboarding first frame, or the top of an empty state — somewhere a word is the whole of what is on screen and worth watching arrive.

It writes one of five built-in words, or paths of your own.

## Installation

TextGlass ships with the library — no separate install.

```tsx
import { TextGlass, Button, Text, View } from 'panelui-native';
```

Or copy the source into your project, to own and edit it:

```bash
npx panelui-cli@latest add text-glass
```

## Usage

```tsx
<TextGlass word="hello" />
```

## Examples

### Basic

`hello` at the default height of 80 points, in the theme's foreground.

```tsx
<TextGlass word="hello" />
```

### The five words

Each is set from the same alphabet, so they sit together at one size.

```tsx
<View className="items-center gap-3">
  <TextGlass word="hello" height={56} />
  <TextGlass word="khalid" height={56} />
  <TextGlass word="hi" height={56} />
  <TextGlass word="welcome" height={56} />
  <TextGlass word="thanks" height={56} />
</View>
```

### Slower, and in a colour of its own

`duration` is the whole word. A heavier `strokeWidth` is in viewBox units, so it scales with `height` rather than against it.

```tsx
<TextGlass
  word="welcome"
  height={80}
  duration={4200}
  color="#6366f1"
  strokeWidth={11}
/>
```

### Writing it again

Remounting on a key is the replay. `onDone` says when there is something to replay.

```tsx
const [run, setRun] = useState(0);
const [done, setDone] = useState(false);

<TextGlass key={run} word="hello" height={90} onDone={() => setDone(true)} />
<Button
  variant="secondary"
  onPress={() => {
    setDone(false);
    setRun((count) => count + 1);
  }}
>
  {done ? 'Write it again' : 'Writing…'}
</Button>
```

### One word after another

`onDone` advancing the index, and the index as the key, is the whole sequencer.

```tsx
const WORDS = ['hi', 'welcome', 'thanks'] as const;
const [index, setIndex] = useState(0);

<TextGlass
  key={index}
  word={WORDS[index]}
  height={80}
  onDone={() => setIndex((at) => (at + 1) % WORDS.length)}
/>
```

### Paths of your own

Three strokes and the box they are drawn in. Each is measured, so the pen keeps one speed across all three.

```tsx
<TextGlass
  height={70}
  viewBox="0 0 240 100"
  strokeWidth={9}
  accessibilityLabel="Signed"
  paths={[
    { d: 'M 20 70 C 30 20 45 20 48 45 C 51 70 40 80 34 72 C 28 64 44 44 70 40' },
    { d: 'M 84 68 C 92 30 104 28 108 48 C 112 68 100 78 96 70 C 92 62 108 44 132 42' },
    { d: 'M 146 44 C 168 36 190 40 206 56' },
  ]}
/>
```

### Held still

`enabled={false}` draws the finished word and never animates it — the same frame reduced motion gets.

```tsx
<TextGlass word="hello" height={70} enabled={false} />
```

## API Reference

### TextGlass

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — |  |
| `word` | `TextGlassWord` | `'hello'` | Which built-in word to write. Ignored when `paths` is given. |
| `paths` | `TextGlassStroke[]` | — | Write something of your own instead of a built-in word. Needs `viewBox`, since nothing else says what coordinates the paths are in. |
| `viewBox` | `string` | — | The coordinate system `paths` are drawn in. Built-in words bring theirs. |
| `height` | `number` | `80` | How tall the word is, in points. Its width follows from the viewBox. |
| `duration` | `number` | — | Milliseconds for the whole word, pen lifts included. |
| `delay` | `number` | `0` | Milliseconds of stillness before the first stroke. |
| `loop` | `boolean` | `false` | Write it again, from nothing, forever. |
| `enabled` | `boolean` | `true` | False holds the word fully drawn instead of writing it. |
| `color` | `string` | — | Ink colour. Defaults to the theme's foreground. |
| `strokeWidth` | `number` | `15` | Width of the line, in viewBox units. |
| `onDone` | `() => void` | — | Called once the last stroke lands. Not called on each pass of a loop. |

Every part also accepts the underlying React Native props (`ViewProps` or `TextProps`) and a `className` for Tailwind utilities.

## Notes

### The five words

`word` picks one of `hello`, `khalid`, `hi`, `welcome` or `thanks`. Each is drawn from a script alphabet rather than stored as a finished shape, so the letters are consistent between them.

The lettering is the component's own. It is not a font, and it does not fall back to one — a device with no fonts installed draws exactly the same word.

### Writing something else

Pass `paths` and a `viewBox` to draw anything. The paths are drawn in the order given, which is the order they are written in, and each is measured so it gets time in proportion to its own length.

```tsx
<TextGlass
  viewBox="0 0 240 100"
  strokeWidth={9}
  paths={[{ d: 'M 20 70 C 30 20 45 20 48 45' }, { d: 'M 84 68 C 92 30 104 28 108 48' }]}
/>
```

A path containing an elliptical arc (`A` or `a`) cannot be measured. Give it a `length` and it is used as passed; leave it out and that stroke draws at the wrong speed.

When you pass `paths`, set `accessibilityLabel` too. A built-in word announces itself; your paths cannot say what they spell.

### Sizing

`height` is in points and the width follows from the viewBox, so a word keeps its proportions at any size. The component takes exactly that box — put the centring on the parent.

### Timing

`duration` is the whole word in milliseconds, pen lifts included, and defaults to a length the word earns: a longer word takes longer. Each stroke's share is proportional to how long its line is, so the pen travels at one speed rather than racing through a dot and crawling through an ascender.

`onDone` fires once, when the last stroke lands. Under `loop` it does not fire again on later passes.

### Writing it a second time

The draw is a one-shot on mount. To run it again, change the component's `key` — there is no imperative replay, because a wordmark that can be restarted from the outside is a wordmark whose state two things can disagree about.

```tsx
const [run, setRun] = useState(0);

<TextGlass key={run} word="hello" />
<Button onPress={() => setRun((count) => count + 1)}>Again</Button>
```

### Reduced motion

The finished word, drawn, immediately — and `onDone` still fires. `enabled={false}` does the same thing deliberately, for a word that should be present without arriving.
