## Installation

Card ships with the library — no separate install.

```tsx
import { Card, Button, Text, Badge, Input, Chip } from 'panelui-native';
```

Or copy the source into your project, to own and edit it:

```bash
npx panelui-cli@latest add card
```

## Usage

```tsx
<Card>
  <Card.Header>
    <Card.Title>Create project</Card.Title>
    <Card.Description>Deploy your new project in one click.</Card.Description>
  </Card.Header>
  <Card.Content className="gap-4">
    <Input label="Name" placeholder="My project" />
  </Card.Content>
  <Card.Footer>
    <Button size="sm">Deploy</Button>
  </Card.Footer>
</Card>
```

## Composition

```tsx
<Card>
  <Card.Header>
    <Card.Title>…</Card.Title>
    <Card.Description>…</Card.Description>
  </Card.Header>
  <Card.Content>…</Card.Content>
  <Card.Footer>…</Card.Footer>
</Card>

{/* behind all of it, in a card that clips */}
<Card className="overflow-hidden">
  <Card.Wash />
  …
</Card>
```

- **`Card.Header`** — Title and description block.
- **`Card.Title`** — Card heading.
- **`Card.Description`** — Muted supporting line.
- **`Card.Content`** — Main body.
- **`Card.Footer`** — Row of actions.
- **`Card.Wash`** — A decorative layer for the back of the card: colour rising from the bottom edge, dithered with grain that breathes. Fills the card absolutely and takes no touches, so it goes first and everything else draws over it.

## Examples

### Full anatomy

Header, content and footer carry the padding, so the card itself never needs a padding class.

```tsx
<Card>
  <Card.Header>
    <Card.Title>Monthly report</Card.Title>
    <Card.Description>Revenue and retention for October.</Card.Description>
  </Card.Header>
  <Card.Content>
    <Text size="3xl" weight="bold">$48,120</Text>
    <Text size="sm" muted>+12% on September</Text>
  </Card.Content>
  <Card.Footer>
    <Button variant="outline" size="sm">Export</Button>
    <Button size="sm">Open</Button>
  </Card.Footer>

```

### Content only

Skip the parts you do not need — nothing is required.

```tsx
<Card>
  <Card.Content className="p-4">
    <Text>A plain surface with a border and a shadow.</Text>
  </Card.Content>
</Card>
```

### An animated wash behind it

`Card.Wash` is the card's back: the tint rises from the bottom edge on a power curve, so it is nothing across the top and arrives in the lower third — a straight fade would read as a tinted panel instead. Over it sits grain, cross-faded between two seedings so each point on the card travels between two values on its own phase rather than holding one forever.

The root needs `overflow-hidden`: the layer reaches the card's edges, and the root is the thing with the corner radius. Put it first — it is absolutely positioned and takes no touches, so everything after it draws on top.

```tsx
<Card className="overflow-hidden">
  <Card.Wash tint="--color-info" />

  <Card.Header>
    <Card.Description>Last 30 days</Card.Description>
    <Card.Title>Weekly active</Card.Title>
  </Card.Header>
  <Card.Content>
    <Text size="3xl" weight="semibold">3,072</Text>
  </Card.Content>
</Card>
```

## API Reference

### Card

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — |  |

### Card.Wash

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | — |  |
| `tint` | `string` | `'--color-primary'` | The colour the wash rises in. A theme token name such as `--color-primary`, or any colour string. Defaults to `--color-primary`. |
| `intensity` | `number` | `0.2` | How opaque the wash gets at the bottom edge, 0–1. |
| `noise` | `number` | `0.35` | How much grain sits over the wash, 0–1. Zero draws the gradient alone. |
| `grainSize` | `number` | `3` | The size of one grain cell, in points. Larger is chunkier and cheaper. |
| `speed` | `number` | `1` | Multiplier on how fast the grain breathes. `0` freezes it on one frame, which is also what a reduced-motion setting does. |

Every part also accepts the underlying React Native props (`ViewProps` or `TextProps`) and a `className` for Tailwind utilities.

## Notes

### Padding lives on the slots

The root carries none, which is why a card whose media reaches its own corners needs nothing but `overflow-hidden` — no padding to undo first.

### Tuning `Card.Wash`

`tint` takes a theme token name or any colour string, and defaults to `--color-primary`. `intensity` is how opaque the wash gets at the bottom edge, `noise` how much grain sits over it, and `grainSize` how chunky that grain is — larger cells are also cheaper, since the tile is drawn once and repeated by the renderer rather than laid out as a grid of views.

`speed` scales how fast the grain breathes, and `speed={0}` freezes it on one frame. A reduced-motion setting does the same thing without being asked: the wash and one still layer of grain are drawn, and nothing loops.
